# GitHub publishing notes

This repository contains illustrative Nagpur demonstration data in `data/`.

The sample area names, coordinates, road distances, resource IDs, and driver names are fictional/approximate demo values, not verified municipal dispatch data. Replace them with verified information before operational use.

Do not commit real credentials, `.env` files, local database files, logs, citizen records, or real staff personal information. The `.gitignore` excludes these runtime and secret files while explicitly including the three demonstration text files.
